# Limpeza de Dados de Vendas — Mercadinho de Bairro

## Sobre o projeto

Neste projeto, estou estudando e praticando limpeza e tratamento de dados com Python e Pandas, usando como exemplo uma situação comum em um mercadinho de bairro.

A ideia é trabalhar com uma base de vendas que contém alguns erros e inconsistências, identificar o que precisa ser corrigido e organizar os dados para que possam ser utilizados com mais confiança em futuras análises.

## O que pretendo desenvolver

- Identificar informações ausentes e registros duplicados.
- Corrigir nomes de produtos e categorias escritos de formas diferentes.
- Padronizar textos e formatos dos dados.
- Conferir se as quantidades, os preços e os valores totais estão corretos.
- Registrar as alterações feitas e explicar o motivo de cada correção.
- Gerar uma nova base de dados e conferir se o resultado está correto.

## Ferramentas utilizadas

- **Python:** para trabalhar com os dados.
- **Pandas:** para analisar, organizar e tratar a base.
- **Jupyter Notebook:** para desenvolver e documentar o processo.
- **GitHub:** para armazenar o projeto e acompanhar sua evolução.

## Como o projeto será desenvolvido

**1. Análise inicial:** entender como a base está organizada e conhecer as informações que tenho.

**2. Identificação dos problemas:** vou procurar erros, valores ausentes, duplicidados e outras inconsistências no DataFrame.

**3. Limpeza dos dados:** o objetivo será resolver os problemas encontrados, tendo foco no cuidado para não alterar informações sem uma justificativa.

**4. Validação:** conferir se as correções funcionaram e se os dados continuam coerentes.

**5. Exportação:** salvar a base tratada em um novo arquivo CSV.

**6. Documentação:** Por fim, irei documentar e registrar os problemas encontrados, as decisões tomadas e os resultados obtidos.

## Organização dos arquivos

- `base_original.csv`: contém os dados antes da limpeza.
- `limpeza_dados.ipynb`: reúne o código, as análises e as validações.
- `log_limpeza.xlsx`: registra as alterações realizadas durante o tratamento.
- `base_limpa.csv`: contém os dados após a conclusão da limpeza.

## Observação

Este projeto tem como objetivo utilizar uma base de dados voltada para simular situações comuns no comércio. O objetivo é praticar habilidades de análise e tratamento de dados em um cenário parecido da realidade, que é enxergado como um problema real.
